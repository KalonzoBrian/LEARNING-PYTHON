## Getting Started

### Prerequisites
- Python 3.x installed on your machine
- A text editor or IDE (VS Code, PyCharm, etc.)
- Basic command-line knowledge

### Installation

Clone the repository:
```bash
git clone https://github.com/KalonzoBrian/LEARNING-PYTHON.git
cd LEARNING-PYTHON
```

### Running the Code

Execute any Python file directly:
```bash
python filename.py
```

Or run a specific script from a subdirectory:
```bash
python basics/variables.py
python projects/calculator/main.py
```

## Key Concepts

### Variables and Data Types
Python supports multiple data types: integers, floats, strings, booleans, and collections.

### Functions
Reusable blocks of code that perform specific tasks. They help organize code and promote DRY (Don't Repeat Yourself) principles.

### Object-Oriented Programming
Python supports OOP with classes, inheritance, and polymorphism for creating scalable applications.

### Error Handling
Proper exception handling ensures programs run smoothly even when unexpected situations occur.
